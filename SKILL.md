# Adaptive Rate Limiter Token Bucket

## Description
Token bucket rate limiter featuring dynamic burst allowance and exponential backoff adaptation for high-concurrency LLM agents.

## Compatibility
- MCP Version: 2025-12-11
- Python: >=3.10 (Standard Library only)
- Supported Platforms: Claude Desktop, Cursor, LobeChat, Smithery

## Tools
Refer to `client.py` and `mcp_server.py` for full JSON-RPC tool signatures.
